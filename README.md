# metadata_extractor

A powerful metadata extraction implementation for Flutter, enabling rich EXIF and media metadata retrieval across platforms.

## Features

- Extract metadata from images (EXIF data, creation time, location)
- Extract metadata from videos
- Built on top of `metadata_core` for standardized metadata models

## Getting started

Add `metadata_extractor` to your `pubspec.yaml`:

```yaml
dependencies:
  metadata_extractor: ^0.0.1
```

## Usage

```dart
import 'package:metadata_extractor/metadata_extractor.dart';

// Use the extractor to process media files
```
